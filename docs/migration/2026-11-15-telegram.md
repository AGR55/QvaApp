# Bot de Telegram en Go — 2026-11-15

## Estado

El bot `@qvaapply_bot` vuelve a responder desde el corte. Usa **long polling**
del notifier Go contra la API del edge; no depende de TS.

```text
servicio     qvaapply-f3-shadow-notifier
modo         NOTIFIER_DRY_RUN=false
polling      TELEGRAM_POLLING_ENABLED=true
autorización solo TELEGRAM_ADMIN_CHAT_ID
edge         http://edge:8093
```

Credenciales y contraseña del panel viven en
`/opt/qvaapply-f3-shadow/notifier.env` (600). El bot elimina cualquier webhook
previo al arrancar y consume los updates con `getUpdates`.

Evidencia:

```text
getMe                       ok · @qvaapply_bot
mensaje de bienvenida       ok · message_id 5049
/help                       handled
/status                     balance 134.85 · 4 ownOffers · 50 operaciones
/markets                    CLASICA compra ≤1.071 · venta ≥1.096
/operations                 operaciones reales con estado
/refresh on                 control.refresh=true
/setrate CLASICA buy 1.071  aplicado sin cambiar el valor
```

## Comandos disponibles

Panel y lectura:

```text
/start /panel /status   /balance   /markets   /offers
/operations   /strategy   /automation   /hunting
/salud   /logs   /revisions   /network /coop   /historial
```

Control:

```text
/pause   /resume
/refresh on|off
```

Configuración:

```text
/setrate MERCADO buy|sell TASA
/setlimit MERCADO QUSD
/setfee MERCADO PORCENTAJE
/fiat MERCADO IMPORTE
```

Operaciones y ofertas:

```text
/paid UUID REFERENCIA
/received UUID
/cancel UUID [ORDER]
/editoffer UUID IMPORTE RECIBE
/canceloffer UUID
/createbuy MONEDA IMPORTE TASA
/createsell MONEDA IMPORTE TASA
```

El panel principal incluye botones inline para Estado, Balance, Mercados,
Ofertas, Operaciones, Estrategia, Automatización y Ayuda.

## Refresco de ofertas propias

El edge lo ejecuta desde `a2958f9`:

```text
intervalo   4 min por oferta (offerRefreshIntervalMinutes)
espaciado   10 s entre ediciones (offerRefreshSpacingSeconds)
prioridad   la oferta más antigua
payload     edición del mensaje para renovar la oferta en QvaPay
control     /refresh on|off → shadow.runtime_settings control.refresh
```

Evidencia de una ronda completa:

```text
21:43:35  oferta propia refrescada 52b3c773-e5ac-4cde-8487-70359f8ced20
21:43:50  oferta propia refrescada 22549487-33a4-420f-8397-21727bc4b3f5
21:44:05  oferta propia refrescada aff332d6-6fe5-4226-b056-17495ae46396
21:44:20  oferta propia refrescada 049c7da0-abe6-48ce-9889-2173f6b0bad6
```

No cambia importes ni tasas: solo renueva la oferta. Los cambios de precio se
hacen con `/setrate`, `/setlimit`, `/setfee` o desde el panel.
