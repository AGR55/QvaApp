# Bot de Telegram en Go — 2026-11-15

## Estado

El bot `@qvaapply_bot` vuelve a responder desde el corte. Usa **long polling**
del notifier Go contra la API del edge; no depende de TS.

```text
servicio     qvaapply-f3-shadow-notifier
modo         NOTIFIER_DRY_RUN=false
polling      TELEGRAM_POLLING_ENABLED=true
autorización solo TELEGRAM_ADMIN_CHAT_ID
edge         http://edge:8093
```

Credenciales y contraseña del panel viven en
`/opt/qvaapply-f3-shadow/notifier.env` (600). El bot elimina cualquier webhook
previo al arrancar y consume los updates con `getUpdates`.

Evidencia:

## Notificaciones de operaciones

El core envía avisos al notifier (`NOTIFIER_URL=http://notifier:8092`) y el
notifier los publica en el chat administrador. Probado con una aplicación real
controlada:

```text
notifier_sent_total    4 -> 5
notifier_errors_total  0
aplicación confirmada  cbb26757-... · 10.00 QUSD · 10.60 USD
cancelación            HTTP 204 · QvaPay volvió a open
```

Formato de aplicación:

```text
🛒 Compra de QUSD aplicada

🌐 Mercado: CLASICA
👤 Contraparte: @usuario (si QvaPay la publica)
💰 Importe: 10.00 QUSD
💸 Debes enviar: 10.68 USD

🔗 https://qvapay.com/p2p/...
```

Al completarse una operación se envía `✅ P2P Completado - Fondos Recibidos`
(o `Fiat Recibido` en ventas) con importe, moneda, contraparte, ID y enlace.

## Cacerías desde Telegram

`/hunting` abre el panel con:

- estado global de compra y venta;
- por mercado: estado de compra/venta y medianas de compra y venta;
- botones «Detener/Activar compra» y «Detener/Activar venta» globales;
- un botón por mercado que abre su detalle;
- dentro del mercado: medianas, tasas, máximo, fee, saldo fiat, botones para
  pausar compra/venta y los comandos exactos `/setrate` para cambiar precios.

La pausa global se aplica de verdad: el hunter y el core combinan
`hunting.buyRunning`/`sellRunning` con `huntBuyEnabled`/`huntSellEnabled` de cada
mercado. Evidencia:

```text
/huntbuy off  -> Compra global: detenida; mercados: "detenida (global)"
/huntbuy on   -> Compra global: activa
/huntsell off -> Venta global: detenida
/huntsell on  -> Venta global: activa
hunt:ZELLE:buy:on/off -> pausa y reactiva solo Zelle
```

Medianas reales mostradas:


## Comandos disponibles

Panel y lectura:

```text
/start /panel /status   /balance   /markets   /offers
/operations   /strategy   /automation   /hunting   /market MERCADO
/huntbuy on|off   /huntsell on|off
/salud   /logs   /revisions   /network /coop   /historial
```

Control:

```text
/pause   /resume
/refresh on|off
```

Configuración:

```text
/setrate MERCADO buy|sell TASA
/setlimit MERCADO QUSD
/setfee MERCADO PORCENTAJE
/fiat MERCADO IMPORTE
```

Operaciones y ofertas:

```text
/paid UUID REFERENCIA
/received UUID
/cancel UUID [ORDER]
/editoffer UUID IMPORTE RECIBE
/canceloffer UUID
/createbuy MONEDA IMPORTE TASA
/createsell MONEDA IMPORTE TASA
```

El panel principal incluye botones inline para Estado, Balance, Mercados,
Ofertas, Operaciones, Estrategia, Automatización y Ayuda.

## Refresco de ofertas propias

El edge lo ejecuta desde `a2958f9`:

```text
intervalo   4 min por oferta (offerRefreshIntervalMinutes)
espaciado   10 s entre ediciones (offerRefreshSpacingSeconds)
prioridad   la oferta más antigua
payload     edición del mensaje para renovar la oferta en QvaPay
control     /refresh on|off → shadow.runtime_settings control.refresh
```

El bucle respeta `control.refresh`: `/refresh off` lo detiene y `/refresh on` lo
reactiva. Evidencia reciente: `22:37:24 oferta propia refrescada
049c7da0-abe6-48ce-9889-2173f6b0bad6`.

Evidencia de una ronda completa:

```text
21:43:35  oferta propia refrescada 52b3c773-e5ac-4cde-8487-70359f8ced20
21:43:50  oferta propia refrescada 22549487-33a4-420f-8397-21727bc4b3f5
21:44:05  oferta propia refrescada aff332d6-6fe5-4226-b056-17495ae46396
21:44:20  oferta propia refrescada 049c7da0-abe6-48ce-9889-2173f6b0bad6
```

No cambia importes ni tasas: solo renueva la oferta. Los cambios de precio se
hacen con `/setrate`, `/setlimit`, `/setfee` o desde el panel.
