# Identidad QvaApply: flujos cruzados

## Objetivo

Sustituir el símbolo actual, cuya mezcla de Q, flecha y gráfica no produce una lectura clara, por una marca abstracta de intercambio que siga siendo reconocible en favicon, sidebar y pantallas pequeñas.

## Decisión visual

El símbolo se compone de dos flujos redondeados que se cruzan dentro de un contenedor azul profundo. El flujo verde representa entrada y liquidez favorable; el ámbar representa salida, oportunidad y ejecución. El cruce central comunica la coincidencia entre una oferta y una aplicación sin recurrir a una letra o una gráfica decorativa.

## Variantes

- `qvaapply-mark.svg`: icono a color de 64 × 64 para favicon, sidebar y estados de carga.
- `qvaapply-mark-mono.svg`: icono monocromático para fondos de una sola tinta.
- `qvaapply-logo.svg`: lockup horizontal del icono con el nombre QvaApply para encabezados y material de marca.

## Criterios

- Legible a 16 px y sin texto.
- Sin sombras, degradados ni trazos superfluos.
- Fondo azul `#123B70`, flujo verde `#35C98B` y flujo ámbar `#F2B84B`.
- SVG semántico con título y descripción.
- Mantener `viewBox` y dimensiones explícitas para evitar saltos de diseño.
